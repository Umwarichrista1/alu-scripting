# api_advanced

Python scripts that use the Reddit API.

| File | Description |
|------|-------------|
| `0-subs.py` | Returns the number of subscribers of a subreddit |
| `1-top_ten.py` | Prints the titles of the first 10 hot posts |
| `2-recurse.py` | Recursively returns the titles of all hot posts |
| `3-count.py` | Recursively counts keywords in hot post titles |

Requires `python3` and the `requests` module.
